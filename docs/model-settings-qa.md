# 模型设置简化与验证

日期：2026-10-09。

## 用户流程

`#/settings/model` 改为居中单列，主表单依次展示 Base URL、API Key、模型名称。首次读取完整设置后才展示表单，避免默认草稿覆盖已保存偏好。字段直接编辑，保存前为草稿，取消恢复已保存配置；“保存并应用”一次提交，从下一次模型调用生效。保存期间禁用字段、取消和目录刷新。已有密钥仅在连接根地址不变时留空沿用，地址改变后必须填写目标服务的 Key；保存后不回显原文。

配置连接后自动读取模型目录，也可主动刷新。列表存在时仍可切换为手动填写，回到列表保留当前自定义名称。读取失败只在主界面提示可手动填写，原始原因收在高级设置。

高级设置默认折叠，保留接口协议、真实额度/用量、模型能力与调用监控；不重置已配置的显式协议。诊断标明来自已保存连接，草稿未保存时禁用主动检测。能力读取不传草稿模型名，主动探测使用保存连接和显式协议。保存成功和连接检测失败分别反馈，不把后续能力读取失败误报为配置保存失败。

## 状态保护

目录 Hook 按服务地址、模型、协议与密钥内存快照去重，不把密钥写入缓存键、日志或新存储。新请求、连接编辑、取消编辑、切换 API 客户端和卸载均使旧请求失效；即使请求不响应取消，序号也会拦截迟到结果。更换模型保留已有目录，地址/密钥/协议变化清空目录。请求失败可以重试，空模型的自动建议不覆盖用户随后输入的名称。

## 连接可靠性修复

配置、能力和监控请求按账号/API 客户端与配置版本归属，保存前发出的旧读取不能覆盖新保存。首次读取失败可原地重试。保存提交携带预期版本和请求 ID，冲突明确反馈；超时结果待确认，不能声称服务端未保存。`GET /agent/settings/requests/{request_id}` 返回持久提交回执，即使后续更新已覆盖最后一次请求 ID 也可确认。未见回执只说明查询时尚未观察到提交；用户可读取最新版本后继续编辑，再次保存受版本检查保护。配置提交与后续连接/图片检测分开显示。

默认连接具有稳定 ID、配置版本及独立凭证引用。Base URL 字段省略沿用，明确清空使用协议默认地址；已配置环境地址在初始化时导入，运行时不再暗中补回。更换 API 根地址、scheme、端口或租户路径时，目录、图片探测和保存均不得隐式携带旧 Key。免密钥 Ollama 不继承其他服务的 Key。数据库失败保留原地址、模型和密钥引用；钥匙串失败不改变数据库；旧明文 Key 仅成功迁移后清除。

目录、健康检查和图片探测具有不超过 25 秒的总预算，包含候选协商与 SDK 重试。HTTP 200 必须具有有效协议响应，HTML、空 JSON 和错误结构不代表健康或接受图片。图片探测读取真实拒绝原因，认证/限流维持检测失败；客户端会发送工具或流式请求与服务实测能力分别展示。实际协商协议和 Gemini 地址标准化用于诊断与监控。

桌面桥接携带请求 ID 与截止时间，取消命令停止异步 HTTP 任务；前端取消后忽略迟到成功与 401。传输取消不表示已提交的写入回滚，保存结果由请求 ID 对账。离线回归覆盖跨服务 Key 流向、失败保存、旧 Key 迁移、慢 GET 覆盖、诊断失败、无效 200、地址匹配及桌面超时/取消。

修复阶段验证：完整后端 553 tests、8 subtests；完整前端 334 tests 与生产构建；Rust 桥接 4 tests 均通过。测试使用临时数据库、合成凭证、MockTransport 或模拟 Keychain，未调用真实模型或操作真实钥匙串；实际服务连接、桌面打包后的系统存储与视觉验收仍待环境验证。

## 多连接与运行绑定补充验收（2026-10-09）

- 五种协议使用 MockTransport 验证真实请求包含档案温度和输出上限；流式与生成共用不可变参数，运行预算只能降低输出上限。
- 多次修改档案后，旧运行恢复原参数和版本；待迁移旧密钥转入安全存储并替换后，旧运行继续读取旧凭证。
- 环境密钥轮换改变 runtime 缓存身份；已有指纹的旧任务明确拒绝凭证替换。升级前没有指纹的历史快照不能反推原凭证；不声称这类快照已验证密钥一致。
- 新增版本表、公开目录、消息和快照均不包含密钥明文；凭证指纹仅在内部绑定中保存，不在公开选择信息里返回。
- 本批后端完整验证：586 项测试、8 个子测试通过；新增 `test_model_profile_parameters.py`、`test_model_catalog_versions.py`。全部使用合成密钥、内存凭证和模拟网络，没有调用真实模型或写入真实系统 Keychain。

## 阶段模型路由 B3 验收（2026-10-09）

- 三个角色调用不同模型；会话明确选模覆盖执行角色，识别和规划仍按各自角色或账号默认。选择原因及策略版本在历史消息的模型详情可查看；没有实际调用的阶段明确标记为“本轮未调用”。
- 策略和三个阶段在首次调用前绑定；修改默认、角色、档案或参数后，恢复读取旧版本。版本缺失、停用、凭证变化及阶段绑定损坏均明确失败。
- 能力明确不支持时阻止调用；未知默认标记未验证，严格模式拒绝未知。目录名称和协议适配器支持不冒充服务已验证能力。
- 上下文检查包含文本、工具定义、系统提示、人设与配置的输出预留；它是保守字节估算。图片用量无法可靠估算时不假报满足文本上下文上限；未配置价格不展示推算金额预算。
- 设置按需读取、CAS 保存、保存期间冻结字段并防止重复请求；冲突保留草稿；离开组件取消等待并忽略迟到结果；保存成功但刷新失败分别反馈。停用的角色模型仍显示原选择并要求修正。
- 后端完整检查：612 项测试、8 个子测试通过。新增路由行为在 `test_model_router.py`，HTTP 契约在 `test_model_catalog_api.py`，历史凭证错误在 `test_chat_model_binding.py`。
- 前端全量 43 个测试文件、363 项测试通过，TypeScript 检查与生产构建通过。UI 自动化组件验证覆盖设置分工及历史消息详情；真实浏览器视觉、系统 Keychain 和真实模型联调仍未验证。当前没有上线 B4 的受限故障切换或 B5 的多模型并行协作。
- 本地后端在确认没有 queued/running Agent 任务后按原启动方式重启，`/health` 返回 200；未创建真实模型调用。实现提交 `7ffa45d`，前置参数与凭证修复提交 `1059d0c`。

### 本地密钥存储判定修复（2026-10-09）

macOS 本地模式不再根据监听地址切换为只读环境密钥，`127.0.0.1`、`localhost`、`::1`、`0.0.0.0` 和 `::` 均使用系统钥匙串。显式 hosted 模式及存储后端覆盖仍有效；其他平台的默认存储行为未改变。已有环境密钥可继续使用，本地存储可写时允许在页面替换个人密钥。配置保存在本地数据库，密钥保存在本机钥匙串，工作区隔离与版本引用保持不变。

验证：存储回归 28 项、模型设置页面 20 项通过；使用模拟钥匙串和合成凭证，不操作真实用户密钥。

### 模型设置弹窗（2026-10-09）

首页表单收为「配置模型」弹窗，主页面展示已保存模型与连接列表。协议选项位于弹窗内，阶段分工与诊断保留在页面高级设置。添加和编辑连接也使用弹窗。关闭或 Esc 取消草稿，点击遮罩不关闭；保存中、结果待确认时禁止关闭，已确认保存成功后关闭。保存错误与连接失败提示在弹窗内显示，已提交密钥仍按原规则清空。弹窗锁定背景交互和滚动，循环键盘焦点，关闭后恢复入口焦点。

验证覆盖：默认收起、打开与取消、保存失败保留弹窗、成功后关闭、保存中和待确认保护、键盘焦点循环、连接新增与失败提示。完整前端 368 项测试及生产构建通过。浏览器交互和截图验收未执行。

### 弹窗细节优化（2026-10-10）

精简重复标题；密钥仅允许显示本次输入，清空、关闭和重新打开后恢复隐藏。超过 8 个模型时提供不区分大小写的搜索，筛选保留当前选择，无匹配仍可手动输入。缺少模型名称或密钥时在操作区解释保存条件，始终提供取消按钮；固定标题，表单区域独立滚动，窄屏按钮扩大。相关页面、连接与应用集成测试 54 项通过；未执行浏览器视觉验收。
