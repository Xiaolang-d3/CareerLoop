# 灯灯品牌定义

名称沿用“灯灯”；Logo 于 2026-10-20 更新为“陪伴小灯”，应用到网页与桌面图标资源。

## 定位

**灯灯 · 你的日常 AI 助手。**

产品理念：**点亮思路，帮助事情向前推进。**

传播语：**一起想清楚，一步步做好。**

优先做好理解意图、接续上下文、分析、起草和根据反馈修改成果。对话是入口，资料按需增强；后续逐步增加工具与有边界的任务执行。品牌定位不是首版已具备所有通用执行能力的承诺。

## 名称与文化意象

灯灯是两个常用字的叠字名称，好读、好写，具有具体形象。文化背景来自日常灯火：让眼前的事情清楚，也陪伴人思考和行动。没有声称该名称出自某句古籍。

Latin 排版 Dengdeng 是拼音表达；应用界面以中文“灯灯”为主。

## 当前 Logo

“陪伴小灯”由暖黄色圆拱灯罩与弧形灯座组成，轮廓直接呼应“灯灯”，表达点亮思路和陪伴思考。用较粗的形体与留白保持侧栏、头像和浏览器标签中的辨识度。

深色应用图标使用深靛蓝圆角底、暖黄灯罩和暖白灯座；透明主标志使用暖黄灯罩与深靛蓝灯座，适合浅色背景。

标志主色 #20213A，点亮色 #FFCB66。应用交互继续使用现有紫色 #6557DC，背景延续暖白与淡紫；暖黄用于品牌点缀。

## 改名与兼容

本轮未增加 Agent 工具或执行权限。模型提示的助手身份同步为灯灯；维护说明见 [agent.md](agent.md)。

桌面配置及图标已更新，现有安装包需要重新构建才能显示新名称和图标；本轮未重新打包、安装或发布。
