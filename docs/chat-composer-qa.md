# 输入框优化验收

日期：2026-10-08。本次仅改输入框，不扩展 Agent 工具或任务功能。

- 内容增长自动调整高度，超过 240px 或视口约 30% 时内部滚动，缩短内容恢复较小高度；窗口/输入宽度变化重新计算。
- 底部操作栏容纳资料、联网、发送/停止，按钮不覆盖文本。
- 输入上限从 1000 调整为聊天 API 支持的 200000 字；接近上限时显示计数。
- 桌面 Enter 发送、Shift+Enter 换行，中文输入确认不发送；触摸设备 Enter 换行。
- 当前 App 内存中的文字草稿按账号与对话隔离，切换或模块卸载后返回恢复。刷新、退出/关闭应用不保存；附件与联网状态不随文字草稿恢复。
- 附件处理中同时阻止发送按钮和表单提交；继续使用现有停止与重试流程。

验证：ChatWorkspace 与 AssistantSurface 共 49 项测试通过，TypeScript 与生产构建通过。新增回归覆盖对话草稿隔离、组件卸载恢复、长文本增高/缩小/滚动、IME与换行不发送，以及资料处理时禁止表单发送。
