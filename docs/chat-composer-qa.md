## 深色主题文字可读性（2026-10-11）

- 原因：旧 `.chat-workspace.has-history .message.assistant .message-markdown` 固定使用 `#36354a`，覆盖正文主题色，在深色消息背景上的色值对比度仅约 1.32:1；引用卡片的子标题、消息编辑信息和来源面板页头也遗留浅色配色。
- 通过随 App 样式统一加载的 `features/chat/styles-dark.css` 覆盖这些固定色值，只作用于深色主题。聊天正文和用户气泡、输入提示、消息操作、引用、来源/记录面板、编辑取消按钮、模型警告和思维导图共享已有语义颜色；生成期间保留模型名称的可读性，发送箭头改用深色字配亮紫背景，悬停与聚焦仍有颜色反馈。
- 使用实际深色主题色值计算：正文在四种主要背景上的最低对比度为 11.75:1，辅助文字为 7.41:1，弱提示为 5.24:1，链接/强调文字为 7.54:1；警告、成功、错误配色分别为 8.00:1、7.18:1、7.06:1。这是配色计算，不能替代真实浏览器对最终样式、透明度和布局的验收。
- 五个相关测试文件共 98 项通过，TypeScript 与生产构建通过。未增加仅匹配 CSS 实现的测试，未改变浅色主题和主题切换逻辑；未调用真实浏览器，视觉验收仍受此前访问限制影响。
