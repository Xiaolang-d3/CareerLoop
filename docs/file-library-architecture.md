# 文件库产品架构

文件库承担两个相连的任务：整理原始文件，以及管理允许 AI 使用的依据。全局导航为首页、AI 工作区、文件库和设置。文件库在左侧栏提供独立入口，聊天顶部不再显示“对话 / 文件库”切换行；设置中的“文件库管理”复用同一组件和资料状态。文件库内部仍提供“文件”“知识”两个入口。

工作区文件模块地址为 `#/chat/library`，设置管理地址为 `#/settings/library`，旧 `#/library` 兼容到工作区文件模块。对话切换时保留已挂载的输入区、未发送附件和当前会话 ID，不停止后台任务；点击侧栏“AI 工作区”恢复当前会话。聊天中的查看资料及已存档成果跳到文件模块，设置概览和账号菜单中的管理入口打开设置路径。两个文件库入口共用 `useLibrary` 与相同存储，操作不产生第二份文件库。文件管理路由只要求资料数据，不因进入管理页强制加载模型能力。

## 文件

文件按目录组织，全部文件、最近使用、收藏、回收站是浏览视图，不是互斥的存储分类。目录、来源和 AI 使用状态可以组合筛选，并与文件名/正文搜索叠加。选择目录后的搜索保留目录范围，清除筛选保留关键词；切换筛选清空文件选择，避免对隐藏的文件执行批量操作。

来源区分导入文件、文本笔记和对话成果。目录选择包含全部目录、未分类及已有文件夹；根目录文件通过“未分类”定位。目录卡片显示未删除文件数量。

默认界面保留搜索、“添加”、浏览分类、主题集合选择器与折叠的“筛选”入口。“添加”提供上传、新建主题集合、文件夹和笔记；视图、时间排序和文件库设置放在右上角更多菜单。筛选展开后选择条件，折叠后仍显示生效范围及清除入口。选中文件时突出“用于对话”，长期使用、集合归属、移动、下载、删除放在更多文件操作中；用途说明仅在选择后出现。

主题集合是多对多关联，一份文件可以加入多个主题，不复制原件或移动目录。选择集合后，目录、来源、AI 使用状态和关键词在集合内继续组合；切换集合清理隐藏的选择。集合内上传或新建笔记会加入当前集合；首次加入可以同时新建集合与添加选中文件，后端事务确保不会部分保存。移出集合或删除集合只解除关联，不删除文件、不改变启用状态。集合中的回收站文件不计入数量，恢复后仍保留关联，永久删除文件时级联清理关联。集合操作在账号工作区事务中验证全部来源后执行。

| AI 使用状态 | 条件 | 用户可做的事 |
| --- | --- | --- |
| 长期使用 | 解析就绪、有正文且启用 | 后续检索、用于对话、改为仅存档 |
| 仅存档 | 有可读正文、未启用 | 独立阅读/下载、用于一次对话、明确开启长期使用 |
| 无可检索正文 | 正文缺失或解析未就绪 | 保留原件、阅读/下载、在阅读器补充 AI 读取内容 |

回收站文件显示已移出知识检索，恢复沿用原启用状态。没有正文的图片和解析失败文件不能冒充知识依据；批量操作含这类文件时禁用用于对话和长期使用，并说明补充正文的入口。文件库界面的上传和新建笔记显式传入 `enabled=false`，默认仅存档；服务及旧 API 调用的默认值保留兼容，现有来源不批量改动。聊天成果存档仍沿用其显式许可。阅读详情直接展示“长期使用”开关，隐私设置单独折叠。

“用于对话”先展示选中文件及用途，再创建新对话，最多 8 个文件，与聊天发送附件上限一致。它只带入当前隐私模式下的文本快照，不启用来源，不请求模型；快照记录来源 ID、标题、更新时间和副本哈希，后续正文校正不会追溯更改快照。其他长期资料仍按既有记忆设置使用，主题集合本身不构成 Agent 检索权限边界。

## 知识

知识页分别展示三个真实数据集：

1. 长期资料：未删除、有可读正文且已启用的文件数量；“查看长期资料”返回文件页并应用对应状态筛选。
2. 待确认知识：展示提议、来源与摘录，用户确认或拒绝后刷新；失败保留提议并显示错误。
3. 已确认知识：展示已确认的知识记录，不把启用文件直接等同于确认其结论。

自动参考遵循现有资料与知识记忆开关。文件存档不等于模型使用许可，进入知识页不触发模型调用。知识审核从原“知识与个性化”弹窗移到知识页；“文件库设置”只保留称呼和后续导入的复杂排版解析选项。

## 实现边界

`library-state.ts` 统一文件是否有正文、来源、知识使用状态和组合筛选的定义。`LibraryFilters` 提供浏览范围，`LibraryKnowledgePanel` 展示资料依据及知识审核；`useLibrary` 同时保留待确认和已确认知识，使用现有 `/library` 数据。

后端 `/library/sources?q=...` 使用来源列表的一个查询快照搜索正文，保留 Unicode 大小写匹配及原排序，不逐文件读取详情。响应只包含现有文件摘要。搜索范围仍由当前认证账号的工作区限定，筛选由前端在该账号列表中组合。

数据库 v31 新增 `library_collections` 与 `library_collection_sources`，升级先保存一致性备份，保留来源、启用状态、原件及现有索引。`/library` 增加 `collections`；集合列表、创建、重命名、删除及成员操作位于 `/library/collections`。不新增 Agent 工具或自主写入权限。目录仍为一层；多级目录、标签、文件版本和语义检索排序需要独立设计。

## 验证

前端回归覆盖组合筛选与正文搜索、隐藏文件选择清理、无正文文件的操作限制、明确启用资料依据、知识与提议的区分，以及既有阅读、隐私、回收站和知识审核失败流程。后端回归覆盖正文与 Unicode 搜索、单次列表查询及账号隔离。浏览器检查文件页、知识页和窄屏布局，截图保存在工作区 `output/file-library-architecture/`，不提交个人文件截图。
