# Banner 设计台首版验收

## 交付范围

在正式 React 聊天中增加按需打开的 Banner 设计台，复用现有生图链路；不是独立 HTML 原型。没有新增后端路由、模型调用参数、数据库结构或依赖。

入口：AI 工作区 → 输入框工具栏「设计台」。

## 已实现

- 主题、风格、配色、目标比例、文案安全区组成完整可编辑的生图指令。
- 准备指令不调用模型；已有草稿必须显式选择替换或保留；用户选用支持生图的模型后点击发送。
- 对话中真实已持久化的生成资产组成候选；跨轮次保留，大图查看、最多四张对比、显示实际尺寸和模型、查看原始文字指令。
- 同名生成文件使用方案序号区分，避免服务默认文件名相同导致候选无法辨认。
- 刷新后从聊天历史恢复图片；表单空白时，「另出一个方向」可复用选中图片的历史文字指令，而非依赖模型记住上下文。
- 原图通过既有账户鉴权接口读取，下载复用原始 Blob；关闭时取消迟到请求并释放对象 URL。
- PNG/JPEG/WebP 页面截图在浏览器内预览，校验空文件、类型、10 MB 限制及解码失败；百分比滑块调整图片覆盖范围，不上传截图。
- 桌面左右分栏，窄屏覆盖布局；手机有图片后先显示当前方案和候选。宽屏内的窄悬浮助手也使用覆盖布局。

## 已发现并处理

- 原有页面 CSS 比新分栏规则更具体，导致面板只剩一个像素；通过实际宽度断言发现，按页面作用域修正规则。
- 手机生成后表单占据首屏；增加结果优先的窄屏顺序，并用元素位置断言守护。
- 浏览器截图在主题和侧栏过渡中截到中间状态；关闭截图动画、等待最终主题颜色，并在各宽度重置面板滚动。
- 全量单测与浏览器测试并行时出现一次初始导航超时；串行重跑及最终相关浏览器回归通过，未通过延长超时或自动重试掩盖问题。

## 警告和边界

- 生图后端测试有一项 Starlette/AnyIO 弃用警告；前端错误边界测试会按设计输出模拟异常；构建仍有原有的大分块体积警告。
- 未使用真实模型凭证或付费额度出图；此次不能验证账户权限、实际延迟、计费或出图质量。
- 本地截图只是 CSS 合成预览，不是模型参考图；不导出合成 PNG，也不修改原图。
- 目标比例只进入指令，不保证服务输出指定像素尺寸；不提供透明背景、局部编辑、主体或风格锁定。
- 表单和本地截图仅在当前工作区临时保留，切换对话或刷新后需要重新填写/选择；候选与原始指令随已保存聊天保留。
- 候选只覆盖当前已加载的历史；通用聊天原有的「重新生成」仍会替换本轮及后续内容，不是保留候选的入口。
- 独立代码复核：通过；未发现阻断性的安全或逻辑问题。复核覆盖显式草稿替换、付费调用边界、本地截图、迟到请求、原始 Blob 下载，并独立验证宽屏内悬浮设计台填满窄容器。
