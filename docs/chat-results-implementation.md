# 聊天成果阅读、导出与归档实施记录

日期：2026-10-11。对应 [调研方案](chat-assets-and-exports-research.md) 的阶段 A 与阶段 B 首期；没有调用真实模型或计费生图接口。

## 本轮已落地

- 回答下方只有一个“成果”入口，在模块内打开阅读弹窗。可切换整条回答、闭合代码块、Mermaid 源码；回答下载 Markdown/TXT，代码按语言扩展名下载。代码块也有自己的下载入口；普通 Mermaid 提供 SVG，思维导图提供 `.mmd` 源码。生成中不提供最终下载/存档，等待用户确认的问句也不作为最终成果；终止/失败后的已有回答标为未完成。
- 聊天、附件和文件库 Markdown 共用渲染器，保留表格、代码折叠、引用与导图；跳过嵌入 HTML。远程 Markdown 图片限制显示尺寸，点击打开原图，失败显示原图入口；不代理下载任意远程地址。
- 历史图片按可见区域加载鉴权缩略图，失败重试；共用附件预览支持同一轮多图切换、缩放与原图下载。缩略图按需生成，不复制附件表。原始文件和缩略图都经过账户数据库与原件路径验证。
- 成果保存选择文件名、现有文件夹，以及默认关闭的“作为知识依据使用”。只有存在可读正文时才能启用；检索使用脱敏文本。图片仅存档，原文件 ready、文本 not_required；未提取文字的文档保留 pending/failed，不能宣称可用于知识检索。
- 保存成功显示“已保存/打开文件”，直接进入文件库完整阅读器。文件库把未启用的聊天成果显示为“仅存档”，原件仍可预览与下载；补充正文后可以启用知识检索。

## 接口和持久化

- `GET /chat/messages/{message_id}/artifacts` 返回账户内成果清单、可检索状态、快照与最新文件夹列表。文本来自后端持久化消息；代码选择器使用闭合围栏的源位置，不信任客户端提交正文。
- `POST /chat/messages/{message_id}/save-to-library` 接收 selector、snapshot、filename、folder_id 与 enabled。终态/消息/附件快照、原文件 SHA-256、目标文件夹和扩展名均由后端校验；过期快照返回 409。
- `GET /attachments/{attachment_id}/thumbnail` 返回受鉴权保护的 WebP，最长 480×320，响应 no-store/nosniff；超大像素图片退回原图下载。
- 复用现有账户工作区的 `library/<source_id>/` 原文件和 `library_sources`。用现有 `source_kind=upload` 存有原件的成果，`metadata.chat_archive.origin` 区分 generated/uploaded。来源中记录聊天/消息/run、实际执行模型与档案版本、引用快照、保存时间和 incomplete；不保存模型凭据或临时授权 URL。
- 对已有表增加返回字段及 metadata 约定，不修改数据库结构、不提升 schema 版本。保留旧 parse_status 兼容字段，并补充 file_status、text_parse_status；补充正文会更新文本状态。
- 写锁内读取消息快照、校验、查找重复成果并写入文件/数据库。同一快照、选择器和保存选项重复请求返回已有条目。文件写入失败回滚记录并清理目录；索引仅在保存提交后按 enabled 执行。文字文件、代码或原附件各自复制为独立文件，删除聊天/附件不会删除存档副本。
- 公网来源仅保留 HTTP(S) 地址，去除凭据、token/key/signature 查询参数；本地引用只包含标题与来源 ID。不会复制其他账户的数据，不把生成内容自动标为已审核知识。

## 后续阶段与边界

阶段 C 尚未实现：需要确认一个生图模型及当前连接可用的生图协议，然后接入本地输出资产、图文有序块、纯图片终态、停止/重放的幂等处理和生成图片保存。当前 `/models`、看图能力和附件展示不能证明网关支持生图；本轮已询问拟使用的生图模型 ID，尚未收到选择。

Markdown 单文件下载保留外链文本，不包含离线图片资源。模型图文资产独立复制、ZIP、排版 DOCX/PDF、思维导图 SVG/PNG、多轮图片编辑仍按原方案后续实现。代码清单首期识别正文中闭合的顶层围栏；未闭合内容只保留在整条回答导出中，不当成完整代码成果。

## 验收

自动化验证使用合成账户、消息和文件；网络/模型不参与测试。覆盖来源清单与凭据过滤、原件字节、代码换行、文件夹、并发幂等、快照冲突、磁盘失败回滚、脱敏索引、纯图片存档、删聊天后独立副本、鉴权/账户隔离、未完成标记、预览焦点与请求取消、导出格式、SVG 生成失败、多图切换和直接打开存档。

真实浏览器布局和截图验收继续受此前访问限制影响，本轮未重试浏览器连接；不能把组件测试和构建当作实机视觉验收。构建仍存在已有 PDF/Mermaid 大分块提示。

最终验证：前端 51 个测试文件、471 项全部通过，TypeScript 与生产构建通过；后端 714 项测试、68 个子测试全部通过。全量并行构建时一次既有模型设置用例超时，单文件回归 19 项与不并行构建的全量复核均通过，未修改模型设置业务。新增接口已通过合成账户 API 测试；本地后端重启以加载接口，前端开发服务保留在 5173。
