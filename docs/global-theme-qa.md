# 全局主题验证

日期：2026-10-09。

## 行为与范围

- 设置首页增加“外观”，独立地址为 `#/settings/appearance`；侧栏保持四个平级入口，首页移除主题按钮。
- 提供浅色、深色和跟随系统。应用入口统一解析偏好，根节点的主题标记覆盖首页、文件库、对话、设置、认证及弹窗。
- 当前设备浏览器通过 `careerloop-theme` 保存偏好，刷新后恢复，同源标签页通过 `storage` 事件同步；默认跟随系统，手动选择后不受系统变化影响。偏好不写入账号服务，也不跨设备同步。
- 没有有效全局偏好时，迁移当前账号的 `careerloop-home-theme:<accountKey>` 并移除该旧键；已有全局选择不被其他账号覆盖。首页显示模式仍按账号保存。
- 存储不可用时，当前窗口仍能切换；无法保证刷新后的恢复。无业务数据迁移、API 或 Agent 权限变更。
