# 今日值得看：空结果与近三天范围验证

日期：2026-10-18。

## 已确认的原因

原缓存为当天完成的空结果。模型监控存在同次 `stage=curation` 成功调用，不能把结果为空直接归因于搜索失败或所有候选缺日期。旧缓存没有逐阶段数量，也没有原始模型输出，无法回溯具体剔除原因。原版只筛选过去 24 小时，且缺少日期的结果在核实原文前被排除。

## 修改

- 用户选择最近三天范围：发布时间窗口改为 72 小时，事件日期保持日精度且必须处于对应日期范围；仍排除未来和过期内容。
- 范围进入缓存契约。旧结果标记过期，仍保留旧范围标签，不重新解释为三天结果。
- 缺少发布日期的公开候选在过滤前补查最多四篇官方原文头部，两路并发。复用已有请求域名白名单、256KB 头部限制和超时；只接受发布元数据，忽略修改时间、普通正文日期及非文章 JSON-LD。
- 保存原始候选、近期候选、原文核实、模型建议、入选和检查排除数量。空结果区分没有近期候选、模型未推荐、建议未通过检查；无法核实日期与真正没有近期结果分开。
- 无合格候选时不调用模型，不标记为“由模型筛选”。旧缓存不补造诊断。生成过程中不把上一版空结果的警告和时间当作当前进度展示。
- 首页显示范围和已核实/入选数量；保持原来的每日一次和显式重筛规则。
