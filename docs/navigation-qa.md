# 全局账号入口验证

日期：2026-10-09。

## 行为

账号菜单在 `App` 中仅通过 `AppSidebar` 挂载一次，首页、文件库、AI 工作区以及各设置页面共用同一入口。内容顶栏仅显示页面标题或显式传入的页面操作，无标题/操作时不保留空顶栏。

桌面入口固定在侧栏底部、折叠按钮上方；菜单向上展开。折叠侧栏时账号按钮居中，隐藏箭头并保留 44px 操作区域。宽度不超过 820px 时使用同一全局导航栏右侧入口，菜单向下、靠右展开；导航层级高于普通内容顶栏与文件库移动工具栏，仍低于模态对话框。

`components/app-navigation-identity.css` 由 `AppStyles.tsx` 最后加载，统一账号槽及菜单定位；首页、文件库原有几何规则移除。菜单内容、认证、退出登录和账户设置行为继续由现有 `AppIdentityMenu` 负责，无路由、API 或 Agent 权限变更。

## 验证

前端全量单元测试：39 个文件、313 项通过。新增 7 项真实应用壳层集成回归，以模拟 API 和页面内容验证五类路由中只有一个侧栏账号入口、跨账号/设置页面导航保持入口，以及折叠侧栏后的菜单操作；顶栏回归覆盖标题、显式操作和空顶栏移除。

TypeScript 检查与 Vite 生产构建通过，保留已有产物体积提示。受此前浏览器工具访问限制影响，本次未完成实机视觉验收，仍需在桌面、折叠侧栏、窄屏及浅深色下复验菜单位置与可见范围。
