# 开发者首页：实现与后续计划

更新日期：2026-10-18（新增主动发现的「今日值得看」）。首页按桌面目录「CareerLoop-开发者首页-定稿」接入。本文描述当前代码行为；本次精选验收见 [home-curation-qa.md](home-curation-qa.md)，原首页视觉验收状态见仓库根目录 `design-qa.md`。

## 已接入的页面

保留灯灯品牌与首页、文件库、AI 工作区、设置四个平级导航，所有分类、筛选及关注设置放在首页模块内。

顶部为本地日期、时间、欢迎语、过去 24 小时动态数、同步状态，以及显示模式、刷新、收藏和兴趣控件。时间按本地时区更新，页面重新获得焦点后校准。主题统一在“设置 → 外观”配置，首页不再提供独立切换按钮。

- **信息模式**：上方 AI / Agent 动态与 GitHub 热榜两列，下方技术栈版本更新、工程实践精选；窄屏单列。
- **简洁模式**：同一批资讯改为密集列表。这是最终定稿确认的含义，取代早期规划的“只显示时间”。
- 首页显示模式仍按账号保存在浏览器；浅色、深色和跟随系统主题由全局 `ThemeProvider` 管理，在当前浏览器的 `careerloop-theme` 中保存，所有模块与登录界面统一使用。没有全局选择时迁移当前账号旧首页主题，已有全局选择不会被其他账号覆盖。详情见 [全局主题验证](global-theme-qa.md)。
- 动态默认 5 条、热榜最多 7 条、实践最多 6 条，可以在模块内展开已有快照。标题、摘要、来源、日期与原文链接可核对。没有真实配图时收起图片区，不使用设计稿示例图代替新闻配图。
- 工程实践不展示封面，含已有缓存图片的条目也使用紧凑文字卡片，不预留图片区或装饰渐变。其他资讯保留真实配图，无图或加载失败时收起图片区。
- AI 动态的 RSS 已有配图优先复用。缺图或只给出 SVG 插画时，仅补取前 6 条原文的 `og:image` / `twitter:image`，最多 3 路并发；只读取最多 256KB 的 HTML 头部，沿用公开域名白名单、超时和禁止重定向限制，图片地址继续由图片域名白名单校验。失败保留列表原图且不影响资讯入库，不随机拿正文或相关文章图片补位；结果随资讯快照缓存，不在每次渲染时重新抓取；工程实践不再补取原文封面。
- 提供加载、无内容、筛选无结果、来源失败保留缓存、收藏、隐藏及撤销状态。

## AI 日报（懒生成）

- 用户在“兴趣设置”中单独选择一个日报模型（`digest_profile_id`，可为空）。未启用时不产生任何模型调用，首页显示配置引导；已保存的档案被停用后日报标记为不可用并提示重新选择。
- 每天首次打开首页时，若当天还没有日报且已有缓存内容，后端在账号工作区后台线程自动生成一次；生成期间前端每两秒轮询直到出结果。系统不常驻，不承诺关闭应用后按日定时生成。
- 日报缓存按「本地日期 + 内容指纹」判定：换天或缓存内容变化后旧日报标记为 `stale`，只提示不自动重调；用户可手动“重新生成”（`POST /home/feed/digest`）或换档案后重新生成。
- 状态：`unconfigured`、`empty`（暂无可总结内容）、`generating`、`ready`、`stale`、`error`；失败保留旧内容并显示可读错误，当天不再自动重试。
- 模型输入仅为已缓存的公开条目标题与摘要（按节限量截断，不含私人资料），提示词要求把条目当作资料、不执行其中指令；输出受总览与要点长度限制，每节最多 4 条，无法对应到原始条目的要点不生成链接。
- 要点可点击回到原文；页脚标注实际生成模型与时间。日报是独立的单次文本调用（调用监控 `stage=digest`），不进入 Agent 记忆、工具或路由。
- 日报和资讯精选的单次摘要调用在档案未明确指定推理强度时默认 `low`，已显式选择的 `low` / `medium` / `high` 保持不变，不修改档案或全局聊天设置。仍遵守原有模型超时上限，不自动重试；外层截止取消也记录 `request_timeout`，避免界面提示超时但监控没有失败记录。真实日报超时复现与修复验证见 [home-digest-timeout-qa.md](home-digest-timeout-qa.md)。

## 今日值得看（每日资讯编辑）

- 首页在原 AI 日报上方增加「今日值得看」，与固定来源列表、标题摘要日报分开。用户在兴趣设置中显式勾选 `curation_enabled`，并选择既有 `digest_profile_id` 文本模型；旧账号默认关闭，不因为原先启用了日报就自动增加搜索请求。
- 启用后当天首次打开首页，按显式关注方向（AI、Agent、MCP、RAG、评测、开发工具）主动发出三组中英文新闻搜索，复用 `research/search.py` 的 Tavily / AgentSearch 适配器及现有搜索开关、凭据和网络安全检查。不需要等待 RSS 有内容；可用的公开缓存也可作为候选补充。
- 每次运行最多三次搜索、每组八个结果；合并 URL 跟踪参数并去重，最多保留十二个最近三天（72 小时）的候选；日期未知的官方来源先按现有采集白名单补查最多四篇原文头部、两路并发，只读取明确的发布时间元数据（不使用修改时间），再排除仍无法核实、未来发布和范围外条目。最多补取四篇缺少正文的网页；只有实际获得正文的候选进入模型，搜索摘要不冒充已读原文。搜索或正文核实失败单独报错，部分失败标注覆盖缺口。
- `backend/app/agent/skills/daily-news-curator/SKILL.md` 是随代码与桌面 sidecar 打包的本地流程资源，不是 Hermes 用户目录里的插件。代码读取它指导一次独立文本调用：区分事件日期与文章发布日期、按事件合并转载、优先原始公告、评估实质变化和开发价值，不凑条数。网页资料不具备指令权限。
- 明确标注“近3天”，缓存契约包含筛选范围；旧 24 小时结果保留原标签并标记过期。保存原始候选、范围内候选、正文已核实、模型建议、入选数量及日期/重复/证据等排除数量；空结果区分无近期候选、模型未推荐和未通过检查。旧缓存不补造诊断；无法核实发布时间不等于今天没有资讯。
- 最多选五条，允许零条；每条有中文标题、事实摘要、推荐理由、来源原文链接、文章发布时间、事件日期、编辑置信度及可展开的逐字正文证据。链接、来源、发布时间由服务端绑定到真实候选，不接受模型自造 URL；验证 ref、评分阈值、事件日期范围和证据逐字匹配。评分/置信度是模型编辑判断，不是测量或独立事实核验。事件日期精度为日，跨源语义去重依赖模型，不承诺识别所有旧闻和转载。
- 账号工作区 `home-feed.json` 中独立存储精选缓存、当日尝试记录与最近三十天/最多一百条事件标识；跨日过滤已有事件，同日重新筛选可以重选。只保存事件标识、URL、入选日期用于去重，不进入 Agent 记忆。当天自动最多尝试一次（失败也不自动循环重试）；兴趣或模型变化只标记 `stale`，可显式重新筛选。
- 运行中合并请求。关闭开关或修改关注方向/模型会使旧运行令牌失效，后续搜索/模型调用前检查，晚到结果不能写入；已经发出的外部请求不能撤回。重启造成的中断提供手动重试提示，不无限轮询。账号相互隔离。
- 原 AI 日报仍独立工作，两者使用同一文本档案但分开计调用与费用。精选每日自动运行最多一次文本请求；手动「重新筛选」会产生新的搜索、正文提取和模型请求。需应用后端运行并访问首页，关闭应用后不自动执行；没有新增常驻 cron、SQLite 表、模型协议或依赖。

## 主流模型官方来源

模型动态覆盖 OpenAI、Claude、Gemini、DeepSeek、千问和腾讯混元；Anthropic 工程实践仍独立保留。Gemini 使用 Google 官方 RSS，DeepSeek、Claude 使用官网文章列表，千问使用官网公开文章目录，混元使用官网公开列表接口（POST 仅查询分页，无写入）。允许列表只增加这些明确的官方域名，保持 HTTPS、禁止重定向和响应大小限制；千问目录包含全文 HTML，单独限制为 8 MB，缓存只提取文章元数据，其余列表保持 2 MB。

首页可按厂商筛选；默认预览优先覆盖各家最新一条，展开后按原始发布时间排列。同一文章按 ID 去重。某厂商七天内没有新公告时保留最近三条旧公告，日期照实展示，过去 24 小时计数仍只计真正近期发布的文章，不把采集时间当作发布时间。国内官网目录每六小时更新，其他动态沿用一小时缓存。

每日精选维持三组、每组最多八条搜索的预算，查询显式覆盖 Gemini、DeepSeek、千问、混元及其他主流模型，证据质量相同时兼顾厂商覆盖；近三天时间窗和不凑数约束保持有效。

## 用户工作流

- 打开原文访问来源链接。
- 收藏保留当时的内容快照。内容离开热榜、超过新闻窗口或取消仓库关注后，仍可从首页“查看收藏”回看；取消收藏移除收藏快照。
- 隐藏只影响当前账号，可以在操作提示中撤销。
- 存入文件库先显示可编辑标题、摘要与原文链接，确认后调用既有 `/library/sources`，默认 `privacy_mode=redacted`。保存的是摘要和来源元数据，不代表已经读取或保存全文。当前没有跨次保存的去重提示。
- 交给 AI 分析通过既有 `/conversations` 创建新对话，将来源信息准备为可编辑草稿，等待用户发送。草稿标明未读取原文全文；已有输入由用户决定替换或保留。账号退出或切换后取消请求并忽略晚返回结果。

## 接口与持久化

| 接口 | 行为 |
| --- | --- |
| `GET /home/feed` | 立即返回快照与日报状态，过期来源后台刷新 |
| `POST /home/feed/refresh` | 合并手动刷新并返回当前快照 |
| `POST /home/feed/digest` | 手动生成/重新生成今日日报；未配置日报模型或暂无内容时返回可读错误 |
| `POST /home/feed/curation` | 显式重新发现、核实并筛选今日资讯；未启用或未选文本模型时返回 422，运行中请求合并 |
| `PUT /home/preferences` | 保存主题、公开仓库关注、日报模型（`digest_profile_id`）与精选开关（`curation_enabled`，省略时保留已有值） |
| `PATCH /home/feed/items/{id}/state` | 保存收藏或隐藏状态 |

源适配器位于 `backend/app/feeds/sources.py`，业务服务位于 `service.py`，日报生成位于 `digest.py`，精选位于 `curation.py`，API 位于 `api/home.py`。`GET /home/feed` 增加独立的 `curation` 状态与结果；前端 `useHomeFeed.ts` 独立加载，后台刷新、日报生成或精选运行期间每两秒轮询；个人操作串行提交，旧账号响应失效。通用首页路由数据依赖仍为空，不为资讯预取会话或文件库。

每个账号工作区使用 `home-feed.json` 保存快照、偏好（含日报模型）、收藏、隐藏状态与日报缓存，原子替换并限制文件权限。没有新增 SQLite 表或迁移，数据库版本仍为 25。个人缓存上限 64 MiB；损坏、结构不支持或超限时返回可见错误并保留原文件，写入超限不会覆盖现有数据。

后台线程显式绑定账号工作区，进程内锁合并刷新；最多四个来源并发采集，每个 worker 继承独立的账号上下文，逐源完成即保存，慢来源不会阻塞其他来源展示。动态、热榜、Releases 缓存一小时，工程实践十二小时；手动刷新最短间隔三十秒，失败来源五分钟后重试。失败保留旧内容及上次成功时间。仅在本地后端运行期间刷新，AI 日报也只在本地后端运行期间懒生成，不承诺关闭应用后持续采集或按日生成。多进程部署需要另加跨进程协调。

固定列表采集使用 HTTPS 来源允许列表，禁止重定向，主列表连接等待十五秒、读写等待二十秒；临时网络错误及 408/500/502/503/504 最多尝试两次，重试预算四十五秒；429 仅在服务给出两秒内 Retry-After 时重试，较长等待交给后续后台刷新。封面补取仍只尝试一次，连接等待五秒、读写等待八秒，公开响应上限 2 MB。来源 HTML 只提取文本；Anthropic 新版工程列表支持 /research/ 文章链接、链接内标题和标题内链接两种结构，以及不含 datetime 的可见 time 日期，未知发布时间不会用采集时间代替。收藏、缓存及用户偏好按账号隔离；固定来源采集、收藏与刷新不调用 Agent 工具或模型。用户启用的 AI 日报和资讯精选各自按所选档案在工作线程内发起独立文本调用；精选的公开搜索与正文读取复用现有研究客户端的来源 URL 安全检查，不把动态域名加入固定采集允许列表。

## 模型选型信息（2026-10-22）

首页优先排列模型能力与成本图表、模型动态、今日值得看；GitHub、工程与技术栈资讯放在其后。动态分类为新模型、能力评测、价格与成本；来源选项根据实际结果动态生成。默认按原始发布时间排列，预览可展开全部缓存条目，不再为特定厂商保留配额。`model_news` 与原 `news` 分开返回以保留收藏和兼容既有消费者。规则标签只根据公开标题/摘要分类，不冒充全文核实。

### 官方 Data API 接入

使用官方账户后台链接的 [新版 Data API 文档](https://artificialanalysis.ai/data-api/docs/reference) 的 `GET https://artificialanalysis.ai/api/v2/language/models/free?page=N`，服务端通过 `x-api-key` 鉴权。旧 `/api-reference` 页面仍列出旧端点，不作为当前契约。免费 API 每个 24 小时窗口 100 请求，分页各消耗一次，要求后端调用、缓存并署名；API 收录范围不等于世界上所有已发布模型。本次不再嵌入官网整页，也不抓取 HTML 表格。

应用管理员在 `backend/.env` 配置 `ARTIFICIAL_ANALYSIS_API_KEY` 后重启后端；[官方平台登录/申请入口](https://artificialanalysis.ai/login)。密钥是独立的公开数据服务凭据，不是 OpenAI 或用户聊天模型的 Key。未配置时不发送请求，`model_benchmarks.status` 为 `unconfigured`，前端显示配置提示和官方入口，不展示示例或旧 HTML 抓取数据冒充实测。配置字段禁止进入 repr/model_dump；请求头、响应原文及密钥不写入账户快照或前端。

`benchmarks.py` 对固定 HTTPS 地址请求，不跟随重定向，连接十秒/读写二十五秒、所有分页共享四十五秒预算及 4 MiB 上限，不自动重试。按 page/total_pages/has_more 读取全部页（安全上限一百页，超限报错，不截断发布），分页契约或指数版本不一致、任一页失败均保留完整旧快照。401（密钥无效）、403（套餐权限）、429、网络和 JSON/schema 错误均转为固定提示。`aa-data-api-v2` 公开来源使用六小时进程共享缓存与账户持久快照，普通刷新不绕过成功缓存；失败保留旧模型列表与旧采集时间，错误后台重试间隔一小时，用户显式刷新可重试失败请求。无需数据库迁移或新依赖。

`model_benchmarks` 包含 `models`、`status`、`error`、`collected_at`、`source_url`、`docs_url`。模型以官方稳定 ID 为标识，保留所有配置（同厂商不去重、不挑最高分），名称保留思考档位；字段包括综合/编程/Agent 指数、输入/输出单价、综合指数评测每任务成本、输出速度与首字延迟。速度从新版 performance 对象读取，任务成本取 artificial_analysis_intelligence_index_cost.cost_per_task.total_cost；免费接口不提供的数学指数与混合单价不展示。只保留官方字段，缺失或非有限数值为 null，免费价格零仍为零。采集时间不充当发布时间、评测时间或版本。

前端由灯灯绘制散点图，在图内与模块说明署名 Artificial Analysis，明确不是官方图表组件。默认绘制所有具备横纵坐标的模型；缺评分或价格的型号仍在全量明细中，不填零。可切换能力×评测任务成本、能力×速度，点选/键盘聚焦模型查看详情，按任意型号/厂商搜索，并可从实际返回厂商中筛选。参照官网成本图，增加点旁型号标注、自动避让、浅绿色优选方向背景及效率边界虚线；边界根据当前筛选范围计算，综合指数更高且成本更低（速度图则更快）才进入边界，同坐标合并边界顶点但不移除数据点。名称优先标出间隔足够的边界点和各厂商高分型号，随容器宽度最多五个或九个标注、拥挤时略过，所有有坐标的型号仍保留在图中；当前悬停/选中型号优先获得名称标注。可关闭标注或搜索特定型号，不以标注名单限制数据。明细按每页五十行提供全部 API 返回的模型与配置，不设固定厂商名单或最大十二条上限。成本横轴默认使用对数刻度（可切回线性；零成本单独放在最左侧），速度使用线性刻度；单价单位是 USD/百万 token；成本图使用官方 USD/任务，与单价和订阅费区分。速度/首字延迟沿用免费接口返回的中位数，不额外指定 Pro 接口参数。未返回指标的条目显示“未提供”。

保留 [原始榜单](https://artificialanalysis.ai/leaderboards/models)、[评测方法](https://artificialanalysis.ai/methodology)、API 文档及 Arena/LiveBench/SWE-bench/OpenRouter 外链；不同评测不合成总榜。官方公开文档中未找到图表 SDK 或专用 embed API，当前实现是官方数据接入加本地绘图。

### 不限制厂商的动态发现

既有六家官网属于直接来源补充，并非覆盖白名单。加入 [Hugging Face 官方博客订阅](https://huggingface.co/blog/feed.xml) 与 [OpenRouter 博客订阅](https://openrouter.ai/blog/feed.xml) 的跨厂商模型资讯，沿用固定采集 HTTPS 允许列表、2 MB 响应上限、禁止重定向与日期规范化。

启用 `WEB_RESEARCH_ENABLED` 的现有联网服务时，`market.py` 通过现有公开搜索客户端发出三组中英文查询，分别面向新模型/开源权重、国内模型动态、能力评测/价格变化。查询不列举厂商、不受本地模型连接列表限制；新厂商无需改代码才可被搜索发现。每组最多十个结果，复用已有 URL/DNS 检查，只存公开标题、摘要、链接和来源域名；剔除未来和七天之前的搜索结果，未知日期保留为空，去除追踪参数并去重。网络搜索只提供索引覆盖，不能承诺市面上每个模型都有动态；无消息时不填充虚构资讯。

公开发现每六小时缓存，不因普通“刷新资讯”绕过该缓存；失败保留旧内容并至少间隔一小时重试。跨账号仅共享公开检索结果，不共享偏好、收藏或 AI 输出。不调用模型，不读取私人资料；使用已配置的联网服务，其搜索请求可能计入现有服务用量。未启用联网时仍显示固定及社区订阅，不为此报配置错误。

每日精选也改用无厂商名单的全市场查询，仍最多三组搜索、近三天正文证据筛选；编辑策略 `model-market-v2` 写入缓存契约，已有结果标过期，不因此自动重复当日模型调用。日报优先概括模型事件，区分厂商自报与独立实测，保留费用单位。


### 模型评测的四类入口（2026-10-22）

模块顶部提供“语言模型、图像、视频、语音”四个轻量下划线标签，默认语言模型。标签支持方向键、Home/End 与键盘焦点；切换类别时重置不适用的子任务、搜索、厂商与点选状态。

语言模型沿用综合指数、任务成本和速度图表。新增九个独立官方免费媒体榜单，固定调用 `/api/v2/media/{任务}/models/free`：图像的 text-to-image/image-editing；视频的 text-to-video/image-to-video 及各自 -audio 版本；语音的 text-to-speech/speech-to-speech/speech-to-text。子榜单分别保存六小时共享公开缓存和账户快照，单榜失败保留其旧数据、采集时间与错误状态，不覆盖语言模型或其它榜单。服务端统一使用现有 Artificial Analysis Key，禁重定向、固定来源映射、4 MiB 上限、45 秒预算、无自动重试；普通刷新不绕过成功缓存，错误后台一小时后可重试，显式刷新可重试失败榜单。每个子榜单请求分别消耗官方配额。

`model_benchmarks.media` 是独立榜单数组，含 id/category/label/metric/source_url/models/status/error/collected_at。模型身份、厂商、Elo、ci_95、BBA/FDB/τ-Voice 与 AA WER 以官方字段归一化，不采纳额外响应字段；无效或缺失值保留 null，零保持零。返回范围以官方 API 实际收录为准，不自行伪造已淘汰或未上榜模型。

图像、视频和语音合成按 Elo 降序展示并保留 95% CI。语音对话可分别查看 BBA、FDB、τ-Voice；语音识别按 AA WER 升序，显示为百分数。缺分型号仍保留在榜单末尾，评分相同使用并列位次。所有返回型号在可滚动榜单内展示，可搜索和筛选实际厂商，不设厂商配额。不同任务、不同评分不合并总榜。免费媒体接口不包含价格、速度，界面明确说明未提供这些数据，不将语言模型指标套用到媒体模型。


### 图表界面精简（2026-10-22）

评测区仅常驻分类、视图切换、搜索及简短数量提示。厂商、名称标注和成本刻度放入“筛选”展开面板；指标含义与其它来源折叠展示。图像、视频及语音同样隐藏次要筛选，保留任务切换。默认不展示空白点选卡片，只有选中型号才展开真实详情。

语言图通过 ResizeObserver 按实际容器宽度重新计算 viewBox、坐标、刻度间隔和标注布局，不再设置横向最小宽度。宽度不足 560 时图高 380，其余为 450；小于 600 的容器最多标注五个名称，其余最多九个；所有有坐标的模型仍完整绘制。重点标注优先效率边界端点和不同厂商高分型号，当前聚焦/选中型号优先；完整名称及思考配置保留在点提示和详情，标签可省略 Default Fallback 后缀。
