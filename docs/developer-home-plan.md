# 开发者首页：实现与后续计划

更新日期：2026-10-08。用户已确认按桌面目录「CareerLoop-开发者首页-定稿」接入现有首页。本文描述当前代码行为；视觉验收状态见仓库根目录 `design-qa.md`。

## 已接入的页面

保留灯灯品牌与首页、文件库、AI 工作区、设置四个平级导航，所有分类、筛选及关注设置放在首页模块内。

顶部为本地日期、时间、欢迎语、过去 24 小时动态数、同步状态，以及显示模式、刷新、收藏和兴趣控件。时间按本地时区更新，页面重新获得焦点后校准。主题统一在“设置 → 外观”配置，首页不再提供独立切换按钮。

- **信息模式**：上方 AI / Agent 动态与 GitHub 热榜两列，下方技术栈版本更新、工程实践精选；窄屏单列。
- **简洁模式**：同一批资讯改为密集列表。这是最终定稿确认的含义，取代早期规划的“只显示时间”。
- 首页显示模式仍按账号保存在浏览器；浅色、深色和跟随系统主题由全局 `ThemeProvider` 管理，在当前浏览器的 `careerloop-theme` 中保存，所有模块与登录界面统一使用。没有全局选择时迁移当前账号旧首页主题，已有全局选择不会被其他账号覆盖。详情见 [全局主题验证](global-theme-qa.md)。
- 动态默认 5 条、热榜最多 7 条、实践最多 6 条，可以在模块内展开已有快照。标题、摘要、来源、日期与原文链接可核对。没有真实配图时收起图片区，不使用设计稿示例图代替新闻配图。
- 提供加载、无内容、筛选无结果、来源失败保留缓存、收藏、隐藏及撤销状态。

## 真实信息源

| 模块 | 当前来源 | 数据规则 |
| --- | --- | --- |
| AI / Agent 动态 | OpenAI 官方 RSS | 最近七天，按发布时间排序；未知日期保留为空，不计入 24 小时新增 |
| GitHub 热榜 | GitHub Trending 日榜/周榜 | 保留原始名次、总 Stars 与对应周期新增，兴趣过滤不重排来源名次 |
| 技术栈更新 | 用户关注的公开 GitHub 仓库 Releases API | 最多 8 个 owner/repo；排除草稿与预发布，只根据说明标注迁移/破坏性提示 |
| 工程实践 | Anthropic Engineering | 保留原始标题、可获得的摘要和日期；较老文章不冒充最新动态 |

上述来源已经实际请求并验证解析。首页显示原语言内容；未自动翻译，也不调用模型生成新闻。规则标签用于筛选，不等同人工编辑推荐。

兴趣支持 AI、Agent、MCP、RAG、评测、开发工具，默认 AI、Agent、MCP。关注仓库默认空，由用户显式添加，不读取私人文件推断订阅。

## 用户工作流

- 打开原文访问来源链接。
- 收藏保留当时的内容快照。内容离开热榜、超过新闻窗口或取消仓库关注后，仍可从首页“查看收藏”回看；取消收藏移除收藏快照。
- 隐藏只影响当前账号，可以在操作提示中撤销。
- 存入文件库先显示可编辑标题、摘要与原文链接，确认后调用既有 `/library/sources`，默认 `privacy_mode=redacted`。保存的是摘要和来源元数据，不代表已经读取或保存全文。当前没有跨次保存的去重提示。
- 交给 AI 分析通过既有 `/conversations` 创建新对话，将来源信息准备为可编辑草稿，等待用户发送。草稿标明未读取原文全文；已有输入由用户决定替换或保留。账号退出或切换后取消请求并忽略晚返回结果。

## 接口与持久化

| 接口 | 行为 |
| --- | --- |
| `GET /home/feed` | 立即返回快照，过期来源后台刷新 |
| `POST /home/feed/refresh` | 合并手动刷新并返回当前快照 |
| `PUT /home/preferences` | 保存主题与公开仓库关注 |
| `PATCH /home/feed/items/{id}/state` | 保存收藏或隐藏状态 |

源适配器位于 `backend/app/feeds/sources.py`，业务服务位于 `service.py`，API 位于 `api/home.py`。前端 `useHomeFeed.ts` 独立加载，后台刷新期间每两秒轮询；个人操作串行提交，旧账号响应失效。通用首页路由数据依赖仍为空，不为资讯预取会话或文件库。

每个账号工作区使用 `home-feed.json` 保存快照、偏好、收藏及隐藏状态，原子替换并限制文件权限。没有新增 SQLite 表或迁移，数据库版本仍为 25。个人缓存上限 64 MiB；损坏、结构不支持或超限时返回可见错误并保留原文件，写入超限不会覆盖现有数据。

后台线程显式绑定账号工作区，进程内锁合并刷新。动态、热榜、Releases 缓存一小时，工程实践十二小时；手动刷新最短间隔三十秒，失败来源五分钟后重试。失败保留旧内容及上次成功时间。仅在本地后端运行期间刷新，不承诺关闭应用后持续采集。多进程部署需要另加跨进程协调。

采集使用固定 HTTPS 来源允许列表，禁止重定向，连接超时五秒、请求超时十二秒，公开响应上限 2 MB。来源 HTML 只提取文本，未知发布时间不会用采集时间代替。收藏、缓存及用户偏好按账号隔离，不调用 Agent 工具或模型。

## 未实现与后续候选

以下早期规划不属于当前已交付能力：

- 更多新闻来源、事件跨源聚合、项目发现备用源、自定义来源。
- 已读、语言/日期筛选、游标分页；当前“更多”仅展开已有快照。
- 指数退避及按 Retry-After 调度；当前采用固定失败重试间隔。
- SQLite v26 资讯表、共享公共缓存、跨进程刷新租约。
- 重复存库去重、正文提取、自动中文摘要、论文/代码、模型价格跟踪和周报。

## 验证

源解析和业务测试使用确定性数据，覆盖缓存失败、并发刷新、账号隔离、收藏跨源更新保留、未知日期、输入校验及容量保护。前端测试覆盖四模块、筛选、显示偏好、加载/错误、菜单键盘、收藏、隐藏撤销、文件库预览与 AI 草稿。

2026-10-08 全量验证：前端 271 项单元测试通过，TypeScript 与生产构建通过；后端 388 项测试及 8 项子测试通过。随后新增容量保护回归的结果记录在 `design-qa.md`。浏览器已验证桌面实际数据、收藏菜单及可编辑存库后在文件库出现；最终截图、深色和窄屏复验受浏览器工具策略阻塞，未宣称完成视觉验收。
